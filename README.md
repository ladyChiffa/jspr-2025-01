# Первый сервер

## Задача

Запустить простой сервер, слушающий подключения в серверные сокеты.

## Состав классов

Server.java:
- конструктор: создает пул потоков, которые могут обрабатывать запросы к порту
- start: поднимает сокета на заданном порту, при подключении на сокет передает запрос на обработку одному из потоков

Request.java, MultiParameter.java - вспомогательные классы для разбора данных из запросов, пришедших в сокет.

Handler.java - интерфейс для реализации обработчиков

Main.java - создание объекта сервера, создание хендлеров для разных ресурсов, запуск сервера

## Ветки

feature/query - реализация выбора параметров запроса из адресной строки

feature/form - реализация разбора запроса, в котором в body передаются поля формы в формате x-www-form-urlencoded

feature/multipart - *незакончена* реализация сохранения файлов из формы формата multipart/form-data
